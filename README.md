This is a DSS project for L3 Informatique.

**Instructions to run the project:**

1. Put all the files in one folder.
2. Open the folder in VS Code (**File → Open Folder**).
3. Open the terminal (**Terminal → New Terminal**).
4. Type `python app.py` and press Enter.
   *(This will work if Python is installed on your PC. If not, please install Python first.)*
5. You should see a link in the output. Copy it and open it in a browser.
